# 盲人辅助导航 APP

通过手机摄像头和 AI 深度估计，生成立体声帮助盲人感知周围环境。

## 云端编译

点击仓库的 **Actions** 标签 → 选择 **构建 Android APK** → 点击 **Run workflow** 即可云端编译。

编译完成后（约15-25分钟），在运行记录的 **Artifacts** 区域下载 APK。

## 使用方法

1. 佩戴立体声耳机
2. 手机竖直握持，后置摄像头朝前
3. 打开 APP，点击"开始"按钮
4. 点击"开始扫描"，通过声音感知障碍物

## 声音含义

- 高音 + 大声 = 近处障碍物（注意！）
- 低音 + 小声 = 远处物体（安全）
- 左耳响 = 障碍物在左侧
- 右耳响 = 障碍物在右侧
